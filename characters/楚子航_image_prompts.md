## 4. 使用说明

- **默认拿"卡塞尔·基线"生图**（Vol4 执行部专员成年态 · 黑西装 + 皮箱 + 长形袋子 + 银盾徽）。
- **拍战斗场景**：叠 3.2 战斗态 diff。**注意：眼睛必须保持温润黑瞳，不许画金瞳、燃烧瞳、熔岩瞳。**
- **拍校园回忆**：换 3.3 高中版（推荐）或初中版 + 可选叠 3.1 日常态调整。
- **想要单一定妆金句氛围**（狂风暴雨 / 孤峭黑影 / 缓缓拔刀 / 弧形刀刃如冷月）：使用 3.2 战斗态，光影选"冷月光 / 雨夜"变体。
- **所有 prompt 已剔除龙化态视觉参数**（金瞳燃烧 / 铁青鳞片 / 龙化利爪 / 血刺骨 / 骨骼暴突 / 熔岩眼底 / 半龙化 / 翅膀 / 血统符文 / 领域光弧 均在 Negative 或不使用）。

### 眼睛处理复述（硬约束）
- 日常戴"蝴蝶黑"美瞳伪装 → 画面直接呈现"温润黑色瞳孔"，美瞳这层信息不需要画出来。
- 战斗态也保持黑瞳（本 prompt 集为人形态限定；金瞳属于战斗中"抹掉美瞳"后的龙血展示，不属于本集）。
